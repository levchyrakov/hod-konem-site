# Ход конём — сайт клуба настольных игр

Лендинг клуба настольных игр «Ход конём» (Санкт-Петербург). Учебный проект: сайт из ЛР4, доработанный в ЛР5 по дисциплине «Информатика» (ГУАП, гр. 4617, Л. А. Чураков).

**Сайт на GitHub Pages:** https://levchyrakov.github.io/hod-konem-site/

## Структура

- `index.html` — страница целиком (разметка, стили, скрипт);
- `images/` — фотографии: `club.jpg` и обложки игр в `images/games/`;
- `CREDITS.md` — источники и лицензии фотографий.

## Изменения в ЛР5

Каждое изменение делалось в своей ветке и попадало в `main` через pull request.

| Ветка | Pull request | Что сделано |
|---|---|---|
| `game-covers` | #1 | эмодзи на карточках «Популярные игры» заменены фотографиями (6 шт.) |
| `club-photo` | #2 | в блок «О клубе» добавлено фото игрового зала с подписью |
| `web-fonts` | #3 | подключены веб-шрифты Lora (заголовки) и Inter (текст) |

## Промпты для ИИ-агента

Изменения вносил ИИ-агент Claude. Задачи взяты из анализа сайта, сделанного в ЛР4.

1. «Замени эмодзи на карточках раздела „Популярные игры" фотографиями партий в эти игры. Фото возьми с Wikimedia Commons под свободной лицензией, уменьши до 360×180 и положи в `images/games/`. Пропиши `alt` и `loading="lazy"`, источники перечисли в `CREDITS.md`. Работай в ветке `game-covers` и открой pull request».
2. «В блок „О клубе" добавь фотографию игрового зала с подписью, чтобы раздел не состоял из одного текста. Файл `images/club.jpg`, лицензия свободная, оформление как у карточек сайта. Ветка `club-photo`, pull request, источник — в `CREDITS.md`».
3. «Подключи веб-шрифты с кириллицей: Lora для заголовков и Inter для основного текста. Системные шрифты оставь запасными. Ветка `web-fonts`, pull request».

Адрес, телефон и отзывы на сайте вымышлены.
